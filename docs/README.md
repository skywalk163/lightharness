## 工作模式

每轮复刻采用固定工作流：
1. **主Agent写任务分发prompt**：6路并行任务+路M收口
2. **用户手工分发**：将6路prompt分发给不同AI agent执行
3. **6路交付后**：用户说"任务全部完成请查收"
4. **主Agent执行路M收口**：合并验证+全量反跑+性能+docs+git提交
5. **用户手工push git**
