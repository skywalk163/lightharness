### 4 项观察

1. **进程链存活**：
   - `ps -p 57424 -o pid,etime,comm --no-headers`（pnpm dsh:freebsd web）
   - `ps -p 57487 -o pid,etime,comm --no-headers`（node bin.ts web）
   - **⚠️ PID 不硬编码 55645**——rcd daemon 用 `pgrep -f 'sh\[57424\]'` 现场取
   - 两个核心进程都要活着，elapsed 应 ≥ 13h（自 10-02 19:14 起）

2. **swap**：
   - `swapinfo -h`（FreeBSD 没有 `free` 命令）
   - 对比基线：Total 10G / Used 2.9G / Avail 7.1G / 29%（清晨 08:30 数据）
   - 判据：Used 不漂移（±0.2G 内）

3. **loopback 栅栏**：
   - `sockstat -4 -l | grep 3080`（应是 `127.0.0.1:3080`，不外露）
   - `curl -s -o /dev/null -w '%{http_code}' http://127.0.0.1:3080/`（应 401）
   - `curl -s -o /dev/null -w '%{http_code}' http://192.168.1.5:3080/`（应 000/rc=7，LAN 打不开）

4. **温缓存 3 样本**：
   - 在 1.5 盒子上跑 `compiler_bench`（3 例即可，不补 10）
   - 对比基线：冷 1.29s/例、温 0.29s/例、4.4×（清晨 08:30 数据）
   - 判据：冷侧不退化；温侧 3 样本只看量级是否突变
