## 七、验收标准（可量化）

1. **LP-D-012 有明确终态**（不是「待修」三个字），且**带探针路径 + 复现命令 + 证据文件名**。
2. A/B 探针**一条命令可复跑**，跑 2 次结论一致，日志落盘。
3. 容量型探针**有自检**：人为让它「没制造压力」时应报「探针无效」，**不得报通过**。
4. §三 的 4 条遗留**逐条有处置**（1 纠正陈旧 / 2 立规矩 / 3 本任务交付 / 4 留档）。
5. **未修改任何既有测试文件**（用 `git diff --name-only` 证明）。
6. 四件套齐全。

## 八、反跑判据

1. 破坏并发 **B 入口**（或让 B 入口回落到注入式路径）→ A/B 探针应**复红**（A/B 差异消失）。
2. 容量型探针：在**无压力**时应通过；把并发压满时应**触发**——两侧都要有记录。
3. 探针自检：注入「空剔除集合」→ 应报**探针无效**（复现 `Day10 §3.2` 的失败形态，证明自检有效）。
