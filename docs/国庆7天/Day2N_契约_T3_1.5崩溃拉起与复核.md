## 四、rcd 最小改动边界（**用户已解禁，但只允许这一处**）

| | 允许 | 禁止 |

| `/usr/local/etc/rc.d/dsh_web` | ✅ **只在 `command_args` 里加 `-r`**（FreeBSD `daemon(8)` 的 `-r` = 子进程退出后自动重启） | ❌ 改其它 rcd 文件、改 `rc.conf`、改 `dsh-web-run.sh`、改 fork 源码 |
| 盒子其它文件 | ✅ 只在 `~/dswork/ltbench/`（基准搬运区）与日志 | ❌ 改 `~/github/deepseek-harness`（**只读**）、做重构建、长时满负载编译 |

> ⚠️ 改前**先贴出 `command_args` 原文**（这是证据）；改后**再贴一次**。改动必须能一眼看出「只多了一个 `-r`」。

## 五、步骤

1. **预检**（§三）→ 落盘 `T3_preflight.log`。
2. **取证现状**：`command_args` 原文 + `service dsh_web status` → `T3_rcd_before_after.log`。
3. **改 rcd**（§四 最小改动）→ `service dsh_web restart`。
4. **崩溃拉起实测**：
   ```
   pid=$(pgrep -f dsh-web-run | head -1); kill -TERM $pid; sleep 10; sockstat -4l -p 3080
   ```
   期望：**10s 内恢复监听**，且 **PID 与杀前不同**（证明是新进程，不是"没死"）。
5. **loopback 栅栏复核**（别把安全面改坏）：仍严格 **`127.0.0.1:3080`**（非 `0.0.0.0`/LAN IP）；带 token 访问 **200**；非 loopback Host 应被拒（403）。
6. **温缓存复核**：**现场**跑基准（**≥10 样本**），落盘机器/OS/python/样本数/冷·温每例耗时/倍数/被测 SHA，并给出与白天 **7.9×** 的差异说明（同机也会飘）。
7. **（可选，≤20 分钟）真实 LLM 路径补测**：凭据来自 `lightharness/.env` 的 `OPENAI_*`。
   - 若凭据**无法做到「不落盘地注入盒子」** → **只做端点可达 + 鉴权握手**（照 `Day14:24` 的 `curl …/v1/models`），并写明「凭据未上盒」；
   - **绝不**把 key 写进盒子上的任何文件或日志；`set +x`；日志走脱敏管道。
8. **顺手纠正陈旧条目**：在报告里指出 `Day10 §五-1` 已被 `Day14` 实测覆盖；并记录「LLM 凭据其实在 `lightharness/.env`」这一更正。
9. **收尾**：`swapinfo` 复检（证明没压坏盒子）。

## 七、验收标准（可量化）

1. **崩溃拉起**：`kill -TERM` 后 **10s 内自动恢复监听**，且 **PID 与杀前不同**。
2. **自启未回归**：`rc.conf` 与 rcd 安装状态不变。
3. **loopback 栅栏未破坏**：仍严格 `127.0.0.1:3080`；token 访问 200；非 loopback 被拒。
4. **rcd 改动只在 `command_args` 一处**（附改前/改后原文对照，可一眼验证）。
5. **温缓存**：现场实跑（≥10 样本）落盘机器/样本/SHA，并与白天 7.9× 的差异给出说明。
6. **盒子未被压坏**：收尾 `swapinfo` 与预检可比，无新 OOM。
7. 四件套齐全；**日志与报告中无任何密码/token 值**。

## 八、反跑判据（**在一次性副本上做，不动生产盒原件**）

1. 把 rcd 的 `-r` **去掉** → 再 `kill -TERM` → 应**复现**「10s 后无监听、不自动拉起」的原缺口。
2. 破坏 loopback 绑定（改成 `0.0.0.0`）→ 非 loopback Host 应**不再被拒**（证明 403 栅栏判据有效）。
> 若不允许在盒上做反跑 → 出口降级为「正向取证 + 语义说明」（照 `Day14:116-118`），**并在报告里标注未做反跑**。

## 九、砍线与降级

- **150min 上限**。
- **1.5 不可达** 或 **root 不可用** → 出口降级为「**rcd 改前原文 + 一行待改 diff + 完整复现/验证命令 + 待跑清单**」，**不阻塞其它子任务**。
- 改 rcd 后**自启或 loopback 任一回归 → 立即回滚 rcd 原文**，不带着坏配置过夜。
- LLM 补测超 20 分钟 → 停，交「端点握手 + 凭据未上盒」的如实结论。
