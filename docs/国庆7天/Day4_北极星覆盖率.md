| 要素 | 取值 |
|---|---|
| 指标定义 | Z = holdout（lightharness/src 生产模块固定种子抽样）中可「零 LLM token 跑通」的模块比例 |
| 跑通级判定 | 模块挂有真实示例（examples/ 中显式 `从 <模块> 导入` 的 .light），取最小示例用 `lightharness/运行.py` 实跑，退出码 0 → 覆盖；全程 mock/无 API Key，不调用任何大模型 |
| 导入级判定（下限参考） | 探针 `从 <模块> 导入 <顶层符号>` 编译运行 rc=0 且输出 IMPORT_OK |

| 评测脚本 | `lightplugin/数据集/零token覆盖率评测.py`（纯标准库，`--json` 落 `零token覆盖率报告.json`） |
| 实测（2026-10-02 10:02，rc=0） | **Z_跑通 0.9844（63/64）**；Z_导入下限 1.0000（64/64）；未覆盖 0 |

**唯一的「仅导入级」模块：`工具_搜索文件`**——examples/ 中无任何文件引用它（grep 零命中），即没有挂靠的 mock 示例 harness，只能以导入探针判定（rc=0 通过）。这不是语言缺陷，是**示例缺口**；若屏障 D 前想拉满，为其补一个最小 mock 示例即可。

**口径说明（诚实边界）**：「跑通」的判定单位是模块的 mock 示例实跑，不是模块每个函数的语义全测；导入级只证明可编译导入并初始化。两级数值分开出数，屏障 D 以 Z_跑通为准。
