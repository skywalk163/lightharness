## 一、并发任务分解

### S1・Level 6 语法核：无空格分词 + 纯缩进块结构 — **light-merge**

**根因（已定位）**
- boot 编译器 `bootstrap_level5.light` 是 Level 4 语法：需空格分隔 token、`结束` 关键字标块、`。` 分语句。
- Level 6 目标语法（缺失功能分析 §八对照表）：无空格分词（最长匹配）、NEWLINE/INDENT/DEDENT 缩进块、单行块支持。
- **对拍参照**：`bootstrap/level6_generated.py`（Level 6 Python 生成版，含 `最长匹配` :1944、`find_block_end` :626、`编译单行块` :1988）。

**要做**
1. `最长匹配` 分词：多字符关键字（含 `开启类型检查` 等长关键字）优先级匹配，替换空格分词；关键字表与 `src/keywords.py` L0-L4 分层对齐，勿手抄漂移。
2. NEWLINE/INDENT/DEDENT 令牌：`扫` 函数处理 `\n`；缩进栈管理。
3. 纯缩进语法解析：替换 `结束` 关键字系统（保留 `结束` 兼容解析做迁移期双支持，转换工具 `convert_to_level6.py` 配套更新）。
4. 单行块：`如果 x: 语句` 形态。
5. 每步以 `level6_generated.py` 对拍：同一输入 token 流/AST 双实现一致。
6. 测试基线：`tests/test_level6_indent.py`/`test_level6_lexer.py` 保持绿；`bootstrap/test_level6_full.py` 中语法类用例转绿（环境类 errors 归 S4）。

**验收**
- `设x为10`、嵌套 if/while 纯缩进、单行块三类探针，boot 编译器 rc=0 输出与主编译器一致。
- `bootstrap_level6.light` 重生成后 boot 自举管线（`TestBootstrapSelfCompile` 15 例）不回归。

**砍线**：若缩进解析与 `结束` 双支持冲突不可调和，则 `结束` 只保读不保写（转换工具负责迁移），登记差异。

### S2・Level 6 词法扩展：符号运算符 + 跳出/跳过 + 关键字别名 + 反引号 — **light-merge**

**衔接声明（⚠️ 与 S1 同文件）**：S2 与 S1 都动 boot 词法层。**并行开工但分文件边界**：S1 只动 `扫` 的空白/缩进/分词主干与块结构解析；S2 只动关键字表（数据面）、符号→中文映射表、跳出/跳过 codegen 分支、反引号令牌分支。merge 顺序 **S1 先合、S2 rebase 后合**；若骨架冲突过大，S2 顺延到 S1 合入后开工（不阻塞 S3/S4）。

**要做**
1. 符号运算符：`+ - * / % == != < > <= >=` → 映射到既有中文运算符语义（`除` 真除口径与 R114 收口追加对齐，`整除` 用 `//` floor）。
2. 跳出/跳过：break/continue 在 boot 循环 codegen 落地（对照 `src` 主编译器既有实现）。
3. 关键字别名：`若` `否` `遍` `于` `不是`（对照 `src/keywords.py` 别名表，勿自造）。
4. 反引号转义标识符：`` `关键字` `` → `反引号标识符` 令牌。
5. 测试：`test_level6_full.py` 对应语法类用例转绿；新增用例折入既有文件。

**验收**
- 符号运算符/别名/反引号/跳出跳过四类探针，boot 产物与主编译器 rc/输出一致。
- `TestBootstrapSelfCompile` 15 例不回归。

### S3・Level 7 类型注解族 — **light-merge**

**要做**（对照 `level7_generated.py` 参照实现）
1. 基础类型定义：`整数` `文本` `小数` `布尔` `空` `列表` `字典`。
2. 变量/函数参数类型注解：`设x为整数=10`、`段add接收a 整数返回整数`。
3. 复合类型解析：`列表[整数]`、`字典[文本,整数]`。
4. 运行时类型检查开关：`开启类型检查`/`关闭类型检查`（boot 侧最小实现：注解校验器）。
5. 真/假字面量：`真`→`True`、`假`→`False`。
6. 类型注解语法依赖 Level 6 分词/缩进骨架 → **S3 动 AST/类型层文件，与 S1 文件解耦；联调在 M 前做一轮**。

**验收**
- `tests/test_level6_types.py` 保持绿；类型注解探针（变量/参数/复合三类）boot 产物与 `level7_generated.py` 行为一致。
- `开启类型检查` 下类型不匹配探针 rc=1 带行号，`关闭` 后 rc=0。

## 三、铁律（全程遵守，沿用 R111-R114）

1. 子 agent 只改文件 + 验证，**不 commit / 不 push**。
2. 汇报含真实命令 + 退出码，声明「未跑就写未跑」。
3. 判绿以 `new_reds`（与 R114 基线 diff）为准。
4. 提交用显式 `git add` 文件清单，**绝不 `git add .`**。
5. 只认 `git ls-remote` 核验推送。
6. 不擅自打 tag；不真发 PyPI；不改测试断言来变绿（重钉须附根因注释）。
7. Edit 落盘后立刻 grep 复核。
8. **语义改裁决必须三处同步记账**（R114 教训）：折叠器 + 两生成器 + 文档注释，一处都不能留旧口径。
9. 本机资源紧张：全量门禁走 0.82/0.86 远端，本机只做定向探针与单文件反跑。
