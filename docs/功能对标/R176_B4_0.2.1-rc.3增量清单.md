## 3. 架构面对齐建议（本轮只登记，未改装配）

1. **工作区根统一出口**：lsp（#339）与 deliverables/tool-present 均从 `session.header.cwd` 迁到 `workingDirectory.ensure(agent, signal)`。本仓若后续引入同类服务，应把「工作区根」收敛成单一入口，禁止各处直读会话头。
2. **变更捕获改由 fs 层提供路径**（#337）：这是「谁负责路径解析」的架构决策——从工具名+参数猜测，改为 fs 提供者给出已解析目标。本仓若要接真实落盘层，应同步把 `工区记录器.捕获编辑` 签名迁到 `(path)`。
3. **注册表族统一 resource 声明**：typert registry 新增 `resources` 视图（#330），与既有 local/remotes/lookups/contexts 并列。本仓 `类型注册.light` 若要扩资源声明，应复用同一套「global 保留 + 段名/线名校验」规则，避免两套校验口径。
4. **jobs 生命周期记录入会话日志**（#336）：`job/registered`/`job/settled` 是 log-only 事件，只投影不驱动模型输出。本仓会话事件表若要加同类事件，须保持「不参与模型输出收集」的约束。

## 5. 语言缺陷

本轮撞到 1 条可登记坑（详见 `语言缺陷账.md` L-182）：**保留关键字作形参名时错误定位漂移**——
`段落 X(定义):` 的报错落在**文件末尾的调用行**（「缩进不正确」），而不是出错的形参位置，
定位成本高（R176 实测：改了 3 轮才定位到 `定义` 形参）。同族既有登记：L-181（`定义` 不可作标识符）。
