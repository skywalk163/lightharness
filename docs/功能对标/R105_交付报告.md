### 2.2 循环依赖（本轮唯一的技术难点，实测记录）

`设置页深化` 需要 `设置页` 的 `智能预设元数据表 / 预设按序 / 内置插件概览 / 内置插件按模式 / 默认预设标识`。
两边都写 `从 X 导入 名` 时，**无论哪个模块先被加载都会撞上半初始化模块**：

- 入口 = `设置页` → `设置页深化` 取不到 `智能预设元数据表`（`设置页` 还没执行到段落定义行）
- 入口 = `设置页深化` → `设置页` 取不到 `渲染模型页`（`设置页深化` 还没执行到段落定义行）

两次实测报错原文：

```
cannot import name '智能预设元数据表' from partially initialized module '设置页' (most likely due to a circular import)
cannot import name '渲染模型页' from partially initialized module '设置页深化' (most likely due to a circular import)
```

**解法**：两边都改成 `导入 <模块>`（只绑定模块对象，不在导入期取属性），调用点走 `模块.段落()` 点号访问。
Python 的 `import X` 对半初始化模块是安全的，属性在**调用时**才解析，那时两个模块都已完整。
`test_设置页`（入口=设置页）与 `test_设置页深化`（入口=设置页深化）两个方向均已验证 rc=0。
