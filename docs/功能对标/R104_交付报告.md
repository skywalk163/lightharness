## 2. 线 A 接线的安全边界（重点复核项）

`src/总入口.light` 是本轮唯一被修改的既有共享文件，`git diff --stat` 实测 **+35 行、0 删除**，
落在参数解析区（`列出会话` 之后、密钥读取之前），**REPL / 列表 / 单轮三条主路径控制流零改动**。

- 合法值：`HARNESS_PRESET=minimal` → rc=0，打印 `--- agent preset: minimal ---` / `挂载条目数: 0  跳过条目数: 1`
- 非法值：`HARNESS_PRESET=zzz` → rc=1，打印 `错误: 未知 agent preset "zzz"` + `可用 preset: standard / ptc / minimal / cordis` 后退出
- 帮助行表追加：`HARNESS_PRESET=standard|ptc|minimal|cordis  会话内切换 agent preset（空串不指定；未知值报错退出并打印可用四键）`

⚠️ **一处真实偏差（口径差，非缺陷）**：minimal 下挂载数为 0。原因是总入口注册表当前只注册 `bash` 一个工具，
不在 minimal 的扁平 id 集（persona / pty / terminal-bash / persistent-bash / terminal-pwsh / persistent-pwsh）内。
属装配数据的真实结果；后续工具按组合 id 注册后该分叉会直接产出非空挂载表。
