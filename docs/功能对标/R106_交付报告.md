## 三、生效链契约（单一真值源，映射表只 A 线一处）
- `src/设置生效.light`：`权限档位表` = `readOnly→全拒绝 / workspaceWrite→按类别 / fullAccess→全放行`；`生效参数(已存设置表, 系统偏好="light", 运行时预设=空)` 输出七键（主题/字号/语言/链接目标/权限档位/权限预设/降级项）。
- 服务端权威：`/api/settings/effective` 直接给最终主题（解析 system 用 `系统偏好` 参数），前端**不得**再自行判定 system（修订 A2，避免两套真值源）。
- 权限优先级：运行时预设非空→原样采用（来自 `权限管理器.当前预设()`），否则回退设置表。
- 快捷键规则权威在 D 线模块；前端只回显服务端 `错误` 文案，不自查保留/冲突（避免第二张权威表）。
