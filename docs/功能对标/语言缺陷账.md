> 汇总后移交光明开发团队（A9 泳道）。

## L-084（第11轮任务6 测试支撑域，2026-09-12）

**现象**：赋值关键字 `为`（`己.x 为 y`）在词法层恒为独立 KEYWORD，即使黏在中文标识符尾部也会被切碎——`行为`→`行`+`为`、`末位行为`→`末位行`+`为`、`全部行为`→`全部行`+`为`、`消耗行为`/`造行为响应`/`选随机行为` 同理。后果：类属性默认值 `属性 末位行为 等于 ""` 解析为属性名=`末位行`、再把 `为` 当赋值符，后续 `等于` 变成无主表达式，报「意外的标记: 换行」（行号常落在被切碎行的 `""` 后，具误导性）。`从 X 导入` 的导入名、模块级 `设 全部行为 为 [...]` 同样被切。字符串字面量内的 `"行为"` 不受影响。

**最小复现**：`类 T: 属性 末位行为 等于 ""` → 解析错误（行 列 落在 `""` 后换行）；词法器实证 `行为` 切成 `IDENTIFIER 行`+`KEYWORD 为`。

**期望**：`为` 作为块内赋值符应做上下文感知（软关键字），标识符位置不拆分；与 L-004/L-021/L-025 同族。

**绕法（本任务采用）**：所有裸标识符一律避开 `为` 字——`全部行为`→`全部项`、`末位行为`→`末支`、`消耗行为`→`消费脚本`、`造行为响应`→`造脚本响应`、`选随机行为`→`选随机项`、裸变量 `行为`→`命中`。字符串键 `"行为"` 保留不动。

**期望**：① 单字别名在非语句首位置不做关键字判定（或仅在 `:` / 表达式起始处生效）；② 词法判定为关键字后若后续 token 无法构成合法语句，报错文案应显式提示「疑似保留字冲突」而非「缩进错误」。

**绕法（本任务采用）**：标识符完全避开上表（改用 `配置结果` / `目标表` 等词）。复现：`examples/_repro_L119.light`（绕法形态 rc=0）。

## L-120（第14轮任务6 会话标题族域，2026-09-13；任务6 报告 §六；L-084 同族，触发面不同）

**现象**：标识符**并不等于**关键字，但若整串可被关键字序列完全覆盖切分，词法器仍会切开它。实测：`捕获 异常 错误己:` ← `错误己` 被切成 `错误`(关键字) + `己`(K_SELF 单字别名) → 解析报「期望'为'或'等于'，但得到「:」」；而 `捕获 异常 错误甲:` 正常（`错误`+`甲`，而 `甲` 不是关键字 → 整串不可全切分）。即判定条件是「整串可被关键字全覆盖切分」，而非「标识符等于某个关键字」。

**与 L-084 关系**：L-084 是标识符含关键字字样（如 `为` 字在词中）被切碎；L-120 是标识符可被关键字序列**完全切分**（无剩余字符）时仍被切碎，触发面更窄但更隐蔽（`错误甲` 正常而 `错误己` 炸，因为 `己` 是单字别名而 `甲` 不是）。

**期望**：词法器对「可被关键字完全切分但整体是合法标识符形态」的串应优先判定为标识符（maximal munch / 标识符优先），或至少在 `捕获 异常 X:` 等明确期望标识符的上下文不做关键字切分。

**绕法（本任务采用）**：标识符避开可被关键字（含单字别名）全覆盖切分的组合——异常变量名用 `错误甲` / `异常对象` / `捕获到的错误` 等，不用 `错误己` / `错误为` / `错误的` 等可全切分组合。复现：`examples/_repro_L120.light`（绕法形态 rc=0）。

**现象（两面同根：光明沿用 Python 语义，JS 语义不同）**：

## L-131（第16轮任务1 子代理核心域，2026-09-13；任务1 报告）
