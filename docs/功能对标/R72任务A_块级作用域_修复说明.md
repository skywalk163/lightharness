## 二、语法口径（最终定稿）

```光明
# 块级声明：在 如果/否则/遍历/当/尝试 块内书写
如果 真:
    令 块内 为 42        # 块内可见
打印(块内)               # 名称错误（块外不可见）——L-172 验收语义

# 函数/模块顶层（无活跃块）：等价 设（向后兼容）
段落 顶层:
    令 局部 为 7          # 函数级
    返回 局部

# 设 完全不变：函数级泄漏（既有行为）
如果 真:
    设 函数级 为 100
打印(函数级)             # 100（泄漏，既有语义）
```

实现口径：变量名 mangling。块内 `令` 声明的变量在生成 Python 时改写为全文件唯一名
`_令{N}_{原名}`（N 为编译期递增计数器），块作用域弹出即映射失效——块外引用原名，
运行期自然名称错误。选择 mangling 而非生成嵌套 `del`/函数包装，是因为它对既有
语法零侵入、与 L-006（nonlocal 自动检测）、L-078（参数遮蔽）机制天然兼容。

## 三、修复前行为（本次消灭）

- `令` 仅支持 C 风格 `令 X = V`，且与 `设` 同为函数级声明，块内声明泄漏到块外；
- 任务书最小复现（`令 块内 为 42` 块外打印应名称错误）在修复前为解析错误。

## 四、修复落点（light-merge/src/）

1. **ast_nodes_v3.py**
   - `VarDecl` 新增 `block_scoped: bool = False` 字段（默认 False，既有构造零变化）。
2. **parser_stmt.py**
   - `_parse_c_var_decl`：支持 `令 X 为 V` / `令 X = V` / `令 X 等于 V` 三种分隔符，
     统一返回 `VarDecl(..., block_scoped=True)`；报错文案改为「期望'='或'为'」。
   - 类体字段路径只取 name/value，类字段不受影响。
3. **code_generator.py**（SRC 主管线）
   - 作用域栈：`_block_scope_stack`（当前函数块栈）+ `_outer_block_scopes`
     （闭包携带的外层函数块映射，只读）+ `_block_var_counter`（mangling 计数器）；
   - 助手：`_push_block_scope` / `_pop_block_scope` / `_resolve_block_scope_name`
     （内层→外层→外层携带映射）/ `_declare_block_var`（mangle + `_bind_local` 登记，
     参与内置名遮蔽判定与 L-006 nonlocal 检测）/ `_enter_function_block_boundary` /
     `_exit_function_block_boundary`（嵌套段落/方法/匿名函数生成时切断块栈并携带外层映射）；
   - 解析位（命中即重定向 mangled 名）：`_resolve_identifier_name`（读取位，最先于
     self 归一/类属性判定）、`_generate_var_decl`（设 落到已可见块级变量）、
     `Assignment`（裸赋值写穿）、`CompoundAssignment`（`加为` 等）、
     `IndexedCompoundAssignment`/`IndexedAssignment`、`ScopeDeclStmt`（`外层 X` 发射
     mangled 名）、`ParagraphCall`（块级变量持函数值时的调用目标解析）；
   - 块体 push/pop：如果（then/else/elif）、遍历、当、C 风格 for（body+increment 同层）、
     尝试/捕获/最终、裸 Block；
   - 函数边界：`_generate_paragraph`、类方法生成、lambda 块体（LambdaExpression 多语句分支）。
4. **code_generator_unified.py**（unified/ANTLR·REPL 后端，对齐）
   - 同套块作用域状态与助手（其无 local 追踪与 L-006 机制，`_declare_block_var` 免登记）；
   - `_resolve_name` 读取位最先做块级解析；`_generate_var_decl` 两条支线；
   - 如果（含恒真/恒假死代码消除路径、elif 链、否则）、遍历、当、尝试/捕获/最终 push/pop；
   - 复合赋值写入位解析；`getattr(stmt, 'block_scoped', False)` 兜底——v2 AST
     （`VariableDeclaration`）无该字段，行为零变化。

## 五、已知交互与边界（均为既有行为，非本次引入）

1. **块内具名嵌套段落被解析器提升到段落层**（AST 实证）：`段落 加:` 写在 如果 块内时，
   解析器把它及其后语句整体提升到段落层（脱离块）。因此块级变量对具名嵌套段落不可见，
   引用即运行期名称错误——符合 L-172「块外名称错误」语义；如需闭包捕获块级变量，
   用 `段落 接收 …:` 匿名段落表达式（生成时机在块栈活跃期内，捕获/写穿语义完整）。
2. **lexer 上下文切词两则**（与本任务无关，探针过程实证）：多行匿名闭包后的行首
   单字 `加(` 会被切成中缀运算符（变量避开单字动词即可）；`加三` 类「动词+中文数字」
   会被切成 动词+数字 两 token（R71-B 已登记的既有判据）。
3. **ANTLR/unified 后端**：`antlr4-python3-runtime` 与生成词法器在本环境缺失，
   unified 端无法端到端运行（修复前同样不可运行，非本次回归）；v3 `令 X 为 V`
   解析支持位于 light_parser_v3（SRC 管线），unified 对 v3 节点到达时的行为已对齐。
