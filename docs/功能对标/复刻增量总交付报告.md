  - **根因 A（致命误报）**：`src/交互命令.light` 原从 `内置核心字符串` 导入 `字符串长度`，但该符号真身在 `字符串工具轻量.light`（第 17 行导出），导致整模块导入失败、所有 `校验提问请求(...)` 调用被连锁误报为「语法错误」。修复：拆成两行，分别从 `内置核心字符串` 与 `字符串工具轻量` 导入。
  - **根因 B（解析器上下文相关 bug，新缺陷 L-066）**：函数调用实参为「含嵌套集合的字面量」或「实参本身为另一函数调用」时，若该调用不在函数体首条语句位置，解析器误判括号闭合（「期望 } 但得到 )」）并级联误报。绕法：所有调用结果、含嵌套集合的字面量一律先 `设` 变量再当实参。此 bug 极具迷惑性——会与前序「错导入」连锁，排查时极易被引向错误方向。
  - **附带修正（原测试逻辑 bug，非语言缺陷）**：① 合法提问请求原用故意不匹配字段却期望返回 空，已改合法数据；② 合法命令序列的 `sourceEventSeq` 原指向 command 事件自身（非法），已插入中间非 command 事件修正。
