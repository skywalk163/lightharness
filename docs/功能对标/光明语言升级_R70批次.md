## 2. 语法新增

### 2.1 匿名函数（任务 A，L-173）

#### 语法

两种形式：

```光明
# 单行表达式体（自动返回）
设 加倍 为 函数(x): x * 2

# 块体（需显式 返回）
设 温和 为 函数(x):
  设 折半 为 x / 2
  返回 折半 + 1
```

#### 语义

- **闭包捕获**：自动捕获外层作用域变量
  - 读取外层变量：自动捕获（Python closure 语义）
  - 修改外层标量：自动生成 `nonlocal`（与 L-078 命名嵌套函数一致）
  - 修改外层可变对象（列表/字典）：无需 nonlocal，直接操作
- **一等值**：可赋值给变量、作为参数传递、作为返回值
- **参数遮蔽**：匿名函数参数名可与外层变量同名（shadowing 合法）

#### 使用示例

```光明
# 作为回调参数（内联在调用实参里）
设 翻倍 为 列表(映射([1, 2, 3], 函数(x): x * 2)))
# 翻倍 = [2, 4, 6]

# 高阶函数（返回闭包）
设 制造加倍器 为 函数(倍数):
  返回 函数(x): x * 倍数
设 三倍 为 制造加倍器(3)
三倍(7)  # = 21

# 闭包修改外层标量（自动 nonlocal）
设 计数 为 0
设 自增 为 函数():
  计数 为 计数 + 1
  返回 计数
自增()  # = 1
自增()  # = 2
计数     # = 2（外层变量已被修改）
```

#### 对 R69 异步代码的简化

R69 异步子进程中，回调派发采用"实例属性暂存 + 无参派发方法"绕法：

```光明
# 旧写法（R69）：
己.待派发结果 为 结果          # 暂存回调参数
己.循环.立即调度(己.派发完成)  # 无参方法读取后调用

段落 派发完成:                  # 额外的无参派发方法
  设 结果 为 己.待派发结果
  己.完成回调(结果)
```

有了匿名闭包后可简化为：

```光明
# 新写法（R70+）：
己.循环.立即调度(函数(): 己.完成回调(结果))
```

无需暂存属性和额外派发方法。

### 2.2 async/await 协程语法（任务 B）

#### 语法

```光明
# 异步段落定义（编译为 async def）
异步 段落 延迟打印 接收 消息, 毫秒:
  等待 睡眠异步(毫秒)
  返回 消息

# 等待表达式（编译为 await）
异步 段落 主:
  设 a 为 等待 延迟打印("hello", 100)
  设 b 为 等待 延迟打印("world", 100)
  打印(a + " " + b)  # "hello world"，总耗时 ~200ms（顺序执行）
```

#### 并发原语

- `全部(任务列表)`：等待所有任务完成（类似 `asyncio.gather`）
- `睡眠异步(毫秒)`：异步睡眠（不阻塞事件循环）

```光明
# 并发执行
设 任务1 为 延迟打印("并发1", 100)
设 任务2 为 延迟打印("并发2", 100)
设 结果 为 等待 全部([任务1, 任务2])
# 结果 = ["并发1", "并发2"]，总耗时 ~100ms（并发）
```

#### 运行时入口

- 模块级 `异步 段落 主` 自动被事件循环驱动（`asyncio.run(主())`）
- 普通同步代码中调用异步函数返回"任务对象"，需 `等待` 或提交到事件循环

#### 错误处理

`等待` 中的异常正常传播到 `尝试/捕获`（与同步代码一致）。

#### 约束

- `等待` 只能在 `异步 段落` 内使用，在同步段落中使用报编译错误："等待 只能在异步段落中使用"
- 现有回调式异步代码（R66 事件循环、R69 异步子进程/PTY）不受影响，async/await 是新增语法

## 5. 迁移指南

### 5.1 匿名函数迁移

**旧写法（命名段落绕法）**：
```光明
段落 加倍回调 接收 x:
  返回 x * 2
设 结果 为 映射(列表, 加倍回调)
```

**新写法（匿名函数）**：
```光明
设 结果 为 映射(列表, 函数(x): x * 2)
```

旧写法仍然兼容，非必需迁移。

### 5.2 async/await 迁移

**旧写法（回调地狱）**：
```光明
异步运行(["echo", "hello"], 配置,
  函数(结果):
    打印(结果.输出)
    异步运行(["echo", "world"], 配置,
      函数(结果2):
        打印(结果2.输出)))
```

**新写法（async/await）**：
```光明
异步 段落 主:
  设 r1 为 等待 异步运行(["echo", "hello"], 配置)
  打印(r1.输出)
  设 r2 为 等待 异步运行(["echo", "world"], 配置)
  打印(r2.输出)
```

旧回调式写法仍然兼容，非必需迁移。

## 7. 已知限制与后续计划

### 7.1 块级作用域（L-172，留待 R71+）

光明当前变量作用域为函数级（类似 Python），`如果`/`遍历`/`当` 等块内定义的变量会泄漏到块外。真正的块级作用域（`令` 关键字）计划在 R71+ 实施，详见 `docs/功能对标/R70任务C_块级作用域与嵌套段落加固_方案决策.md`。

### 7.2 匿名递归限制

匿名函数无法直接递归（无名字），如需递归用命名 `段落`。这是预期限制。

### 7.3 语法限制（记录备查）

- 匿名闭包在括号内不支持块体（IIFE 模式需先设为变量）
- 递归调用在复合表达式中需分步（`返回 n * 递归(n-1)` 需拆为两步）
