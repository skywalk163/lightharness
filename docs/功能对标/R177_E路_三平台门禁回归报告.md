## 6. 环境坑（本轮新踩，务必写进台账）

### 6.1 `LIGHTPLUGIN` 未注入 → 整轮假红（已 A/B 实证）

worktree 的父目录没有 `lightplugin/`，`运行.py` 的默认解析（`ROOT/../lightplugin`）落空 → `_lightplugin_paths()` **静默返回空表**。首轮全量因此出现大量红，作废重跑。

```
pytest tests/test_回归.py -k 插件 -o addopts=
  无 LIGHTPLUGIN → 2 failed, 5 passed
  有 LIGHTPLUGIN → 7 passed
```

**结论**：LH 全量门禁必须显式 `export LIGHTPLUGIN=<仓根>/../lightplugin`，否则红是假的。R128 文档（P-06）只写了远端要带 lightplugin，没写本机 worktree 场景。

### 6.2 `--basetemp` 复用 → xdist 启动期 INTERNALERROR

第二次跑同一 `--basetemp` 目录时，xdist `getbasetemp()` 会先 `rm_rf`，被本机 safe-delete shim 拦成：

```
OSError: [Errno 67] 找不到网络名。: '\\?\C:\Users\...\T-0177\.hive\pt'
```

**处置**：每轮开跑前 `rm -rf .hive/pt`（或换新 basetemp），不要让目录已存在。

### 6.3 `scripts/多平台矩阵.py` 在 worktree 里跑 = **0 用例假绿**

`ROOT = parents[1]`，`LM_LOCAL_CWD = ROOT.parent/"light-merge"`。在 hive worktree 下 `ROOT.parent` 是 `~/.hive/wt/workbuddyai-win`，那里没有 `light-merge` → `no tests ran`（rc=5），**但脚本仍打印「✅ 零新增红 / PASS」并写了一份 0 用例基线**。

### 6.5 `lm-full` 自比恒为 0（假绿）

`scripts/多平台矩阵.py:808-810`：

```python
hist = _lm_history(prefix)          # 排除 *_latest.json，但不排除「刚写进去的本轮基线」
```
