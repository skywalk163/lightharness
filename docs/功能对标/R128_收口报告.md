## 2. B 路耐久修复与 E-09 销账（重点）

`test_会话冷读_接线.light` 经实证存在**两个正交根因**：

1. **1c 事件数=-1**：`src/持久化.light` 硬编码 Windows 反斜杠 `\\` 作分隔符；FreeBSD 上反斜杠是合法文件名字符 → 路径拼错。修复：`会话目录`/`日志路径` 改用 POSIX 正斜杠 `/`（光明路径语义本即 POSIX，见 `stdlib/内置核心路径.light`）。
2. **1b 会话名顺序**：`冷读列出会话` 直接透传 `文件列表` 的 readdir 列举序，FreeBSD/zfs 不保证 `sess-a` 先于 `sess-b`；反斜杠修后两条会话都能读到、1c 消失，1b 才暴露。修复：两层 `文件列表` 改包 `排序列表(...)` 按项目/会话字典序确定排序。

0.82 实证（`运行.py examples/test_会话冷读_接线.light` 在 **lightharness cwd** 与 **harness 隔离临时 cwd** 两种环境均 rc=0「测试通过」）。据此**销账 E-09**（环境红台账现仅 E-01/E-02/E-06 三条）；该 example 不在 `EXPECT_RED`，销账后转为普通绿用例。

最终基线 `reports/R128_LH_0.82基线_20261009-100618.json`（round=R128-B-E09fix2）：

> **2087 用例 / 2066 passed / 0 failed / 18 skipped / 3 xfailed / 866.566s**，pytest_rc=0。

> ⚠️ **文档勘误**：B/E 路初版报告曾将 1b 归为「只是反斜杠、不是 readdir」，耐久修复实证后订正为「两因正交」；已在 `R128_B路_0.82跑法与冒烟报告.md` §6.5、`R128_E路_门禁回归报告.md` §3.5 补【收口勘误】。
