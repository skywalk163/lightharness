### 2. dsh-jail-run 编译与安装

- **编译**：`cc -O2 -Wall -Wextra -o dsh-jail-run dsh-jail-run.c -ljail`（jailparam_* 在 libjail 中，必须 `-ljail`）
- **安装**：`sudo install -o root -g wheel -m 4755 dsh-jail-run /usr/local/sbin/`
- **验证**：`-rwsr-xr-x root wheel`，setuid 位生效
- **烟雾测试**：`dsh-jail-run --workspace /tmp --mode read-only -- true` 退出码 0

> **FreeBSD stat 注意**：`stat -f '%Lp'` 不返回 setuid 位（显示 755 而非 4755），验证 setuid 应用 `test -u` 或 `ls -la` 查看 `s` 位。

### 3. 进程树 POSIX 分支实测结论（重点）

上游 `进程树.light` 的 POSIX 分支（`setsid` 创建新会话、`killpg` 发送进程组信号）此前**注释明确标注"未在任何 POSIX 机器实测"**。R68 在 FreeBSD 15.1 上首次完成实测：

- **setsid**：子进程成功创建新会话，进程组 ID 与父进程分离 ✅
- **killpg**：向进程组发送信号可正确终止整组子进程 ✅
- **有界输出 + spill**：限尾字节 2048、大输出 50KB 溢出到文件、省略标记正确 ✅
- **总超时 + 空闲超时**：超时杀树生效，退出码/超时标志正确 ✅
- **环境注入**：子进程环境变量传递正确 ✅
- **启动失败**：不存在的命令返回正确错误 ✅
- **失真标志**：输出截断时标志位正确 ✅

**结论：进程树 POSIX 分支在 FreeBSD 上功能完整，无平台语义差异。**

### 4. PTY FreeBSD 行为

| 项目 | Windows | FreeBSD 15.1 | 差异处理 |

### 6. Socket 平台差异（R68 交叉验证新发现）

| 差异项 | Linux | FreeBSD 15.1 | 影响 | 建议 |
|---|---|---|---|---|

| **socketpair(AF_INET)** | 支持 | EOPNOTSUPP (errno 45)，仅 AF_UNIX | test_事件循环.light 使用 socketpair(AF_INET)，直接失败 | R66 事件循环测试改用 AF_UNIX socketpair 或 TCP 回环 |

> 这两项是 R68 交叉验证的正常发现——R66 模块在 Windows/Linux 上开发，FreeBSD 首次暴露平台差异。不影响 jail e2e、PTY、进程树、沙箱等模块。
