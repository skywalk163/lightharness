# 配置参考

本文档列出 lightharness 各模块的配置项。当前版本覆盖遥测模块。

---

## 遥测配置

遥测模块通过 `代理循环` 的 `选项["遥测"]` 传入 `遥测收集器` 实例，或独立使用。配置项如下：

### 遥测.启用

| 项目 | 说明 |
|------|------|
| **默认值** | `true` |
| **取值范围** | `true` / `false` |
| **说明** | 是否启用遥测数据收集。设为 `false` 时，代理循环不记录任何指标。 |

**示例：**
```light
设 代理 为 新建 代理循环(会话, 客户端, 注册表, ["遥测": 遥测实例])
```

### 遥测.输出器

| 项目 | 说明 |
|------|------|
| **默认值** | `console` |
| **取值范围** | `console` / `jsonl` / `otlp`（可多选，逗号分隔） |
| **说明** | 遥测数据输出目标。`console` 输出到控制台；`jsonl` 写入 JSONL 文件；`otlp` 组装 OTLP HTTP 请求结构（接口层预留，未实际发送）。 |

**示例：**
```light
设 管理器 为 新建 输出器管理器()
管理器.注册(新建 控制台输出器(空))
管理器.注册(新建 JSONL输出器("./telemetry/session1.jsonl", 空))
```

### 遥测.JSONL路径

| 项目 | 说明 |
|------|------|
| **默认值** | `./telemetry/{session_id}.jsonl` |
| **取值范围** | 文件路径模板，支持 `{session_id}` 占位符 |
| **说明** | JSONL 输出器的文件路径。每个 span 一行 JSON。路径中的 `{session_id}` 会被替换为实际会话标识。 |

**示例：**
```light
设 路径 为 "./telemetry/sess_001.jsonl"
设 输出器 为 新建 JSONL输出器(路径, 空)
```

### 遥测.OTLP端点

| 项目 | 说明 |
|------|------|
| **默认值** | `""`（空，不启用） |
| **取值范围** | HTTP/HTTPS URL |
| **说明** | OTLP 导出端点。当前为接口层预留，设置后仅组装请求结构，不实际发送 HTTP 请求。 |

**示例：**
```light
设 输出器 为 新建 OTLP输出器("https://otlp.example.com/v1/traces", ["Authorization": "Bearer xxx"], 空)
```

### 遥测.OTLP请求头

| 项目 | 说明 |
|------|------|
| **默认值** | `{}`（空字典） |
| **取值范围** | 字典，键值均为字符串 |
| **说明** | OTLP HTTP 请求头，通常包含 `Authorization` 等认证信息。 |

**示例：**
```light
设 请求头 为 ["Authorization": "Bearer sk-xxx", "Content-Type": "application/json"]
设 输出器 为 新建 OTLP输出器("https://otlp.example.com/v1/traces", 请求头, 空)
```

### 遥测.采集正文

| 项目 | 说明 |
|------|------|
| **默认值** | `false` |
| **取值范围** | `true` / `false` |
| **说明** | 是否在 span 属性中采集提示词/回复/工具参数正文。为 `false`（默认）时，仅保留结构和元数据（token 数、耗时、状态、工具名、参数 hash），不包含正文内容，保护用户隐私。 |

**示例：**
```light
设 遥测 为 新建 遥测收集器()
遥测.配置选项(["capture_content": 假])
```

### 遥测.采样率

| 项目 | 说明 |
|------|------|
| **默认值** | `1.0`（全采样） |
| **取值范围** | `0.0` - `1.0` |
| **说明** | 遥测数据采样率。`1.0` 表示全部记录，`0.0` 表示不记录。当前版本保留配置接口，实际采样逻辑待后续版本实现。 |

**示例：**
```light
# 采样率 0.5 表示约 50% 的 span 被记录
```

| 遥测.采样率 | `1.0` | `0.0` - `1.0` |
