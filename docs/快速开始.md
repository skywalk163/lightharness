# 快速开始

本文档引导你在 5 分钟内跑通第一个 lightharness agent。

## 前置要求

| 依赖 | 版本 | 说明 |
|------|------|------|
| Python | 3.8+ | 运行器与光明编译器均基于 Python |
| 光明语言（LightLang） | 最新版 | lightharness 的源码语言，编译器来自 [light-merge](https://github.com/lightlang/light-merge) 仓库 |
| Git | 任意 | 克隆仓库 |

> lightharness 自带一份自包含 stdlib（`stdlib/` 目录），不依赖光明语言的标准库，只需编译器。

## 安装 lightharness

```bash
git clone <仓库地址> lightharness
cd lightharness
```

仓库结构：

```
lightharness/
├── 运行.py          # 运行器（编译并执行 .light 程序）
├── src/             # 核心源码（会话/代理/工具/客户端等）
├── stdlib/          # 自包含标准库
├── examples/        # 示例与测试
├── docs/            # 文档
└── tests/           # 回归测试
```

## 配置 API Key

lightharness 通过环境变量传递 API 密钥，避免与命令行参数冲突。

**Windows（PowerShell）：**

```powershell
$env:DEEPSEEK_API_KEY = "sk-你的密钥"
```

**Linux / macOS（bash）：**

```bash
export DEEPSEEK_API_KEY="sk-你的密钥"
```

支持的环境变量：

| 变量 | 默认值 | 说明 |
|------|--------|------|
| `DEEPSEEK_API_KEY` / `HARNESS_API_KEY` | （必填） | API 密钥 |
| `HARNESS_ENDPOINT` | `https://api.deepseek.com/chat/completions` | API 端点 |
| `HARNESS_MODEL` | `deepseek-chat` | 模型名 |
| `HARNESS_ROOT` | `sessions` | 会话持久化根目录 |

## 第一个 Agent

创建 `examples/你好.light`：

```light
# 导入核心模块
从 客户端 导入 客户端
从 代理 导入 代理循环
从 会话 导入 新建会话
从 工具 导入 工具注册表

段落 主:
  # 1. 创建 LLM 客户端（端点/密钥/模型）
  设 客户端对象 为 新建 客户端("https://api.deepseek.com/chat/completions", 环境变量("DEEPSEEK_API_KEY"), "deepseek-chat")
  # 2. 创建会话（append-only 事件日志）
  设 会话对象 为 新建会话("demo_001", ".")
  # 3. 创建工具注册表（可注册自定义工具）
  设 注册表 为 新建 工具注册表()
  # 4. 创建代理循环并驱动一轮对话
  设 代理 为 新建 代理循环(会话对象, 客户端对象, 注册表, [])
  设 结果 为 代理.驱动("用一句话介绍光明语言")
  # 5. 打印轮次结果
  打印 "轮次结束: " 加上 结果["种类"]
```

## 运行方式

```bash
# 运行你的第一个 agent
python 运行.py examples/你好.light

# 冒烟测试（验证自包含 stdlib，无需 API Key）
python 运行.py examples/冒烟.light

# CLI 入口（单轮，通过环境变量传消息）
$env:HARNESS_MSG="你好"
python 运行.py src/总入口.light

# CLI 交互模式（多轮对话）
$env:HARNESS_REPL="1"
python 运行.py src/总入口.light
```
