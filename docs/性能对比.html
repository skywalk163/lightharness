怎么选后端？

场景推荐后端原因

一行命令切换

# 默认：Python 解释（零依赖） python 运行.py examples/benchmark.light # ANTLR 解析器（需 pip install antlr4-python3-runtime） python 运行.py examples/benchmark.light --backend antlr # LLVM 原生编译（需 clang，产出 .exe） light compile examples/benchmark.light --backend llvm-typed --optimize O2 -o benchmark.exe ./benchmark.exe
结论：光明语言三套后端共用同一套 stdlib 和 v3.2 语法，业务代码零修改即可切换。 开发期用 SRC 快迭代，发布时用 LLVM 编译成独立 exe——性能和部署体验兼得。
